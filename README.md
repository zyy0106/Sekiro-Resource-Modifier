# Sekiro Resource Modifier

**为已获得的物资补充数量，减少重复刷取，把时间留给探索、练习和战斗。**

Windows 便携版：解压后双击 `Sekiro Resource Modifier.exe`。不需要安装 Python、Cheat Engine、开发工具或额外 Python 库。

> 本工具直接覆盖游戏现有存档，不生成备份、日志或历史版本。保存后不能通过本工具撤销。

## 这个工具的意义

《只狼》的挑战可以来自战斗练习，而不必总是来自反复刷取消耗品。本工具允许玩家自行调整已获得的钱币、纸人、糖和药品等资源的数量，减少重复劳动。

它**不是道具解锁器，也不是通关或剧情跳过工具**：

- 只补充所选存档中已有物品记录的道具，不生成尚未获得的物品。
- 不提前发放未知道具、首领奖励、剧情奖励或关键物品。
- 不解锁技能，不提升攻击力，不修改剧情事件标记。
- 不提高葫芦升级等级或纸人携带容量。
- 不提供无敌、无限冻结、自动战斗或游戏启动功能。
- 不替玩家完成探索和获取道具的过程。

物资数量变化仍然会影响资源管理和游戏平衡，是否使用、补充多少由玩家自行决定。“已获得”在技术上指**当前存档仍有该物品记录**；如果记录已经消失，工具不会猜测历史获得情况，也不会自动生成该道具。

## 下载与运行：普通玩家无需配置环境

1. 打开本仓库的 **Releases** 页面。
2. 下载 `Sekiro-Resource-Modifier-v1.0.0-Windows-x64.zip`，不要把 GitHub 自动生成的 `Source code.zip` 当作可运行版。
3. 右键 ZIP，选择“全部解压”。
4. 打开解压后的目录，双击 `Sekiro Resource Modifier.exe`。
5. 保留 `使用说明.txt`、`SHA256SUMS.txt` 和第三方许可文件，方便查阅与校验。

当前仓库是私有仓库。下载者需要先登录 GitHub，且拥有仓库访问权限。

便携版已经包含运行时、Tkinter 界面组件和物品参数，不依赖电脑上是否安装了 Python。可以放在桌面或普通文件夹，不需要管理员权限。

### 支持范围

- 目标系统：**Windows 10 / Windows 11，64 位 x64**。
- 目标游戏：**《SEKIRO: Shadows Die Twice》PC Steam 1.06 存档格式**。
- 必须拥有游戏，并已经在游戏内建立有效存档；“无需环境”不表示无需游戏或存档。
- 不承诺兼容主机版、Windows ARM 原生环境、旧版 Windows、其他存档格式或未来游戏版本。
- 已通过 39 项单元／GUI 测试，并验证独立 EXE 在仅保留 Windows 系统 PATH、移除 Python 环境变量的条件下能加载界面、读取参数并保存合成存档。
- 这不是洁净虚拟机测试；没有在每一种出厂电脑或所有 Windows 版本上逐台验证。

这是未做商业代码签名的个人工具。如果系统安全策略阻止运行，先核对下载来源与 SHA-256，并遵循本机安全策略；本工具不会关闭防护或修改安全设置。

## 使用步骤

1. **从游戏菜单正常退出**，等待 Steam 云同步完成。
2. 打开 `Sekiro Resource Modifier.exe`。
3. 顶部“游戏数据”会自动列出 `%APPDATA%\Sekiro\*\S0000.sl2`。如果有多个账号目录，选对文件。
4. 在“存档”下拉框选择要修改的有效存档槽。
5. 修改钱币，或选择物品后分别输入“随身”和“仓库”数量。物品目标会自动更新。
6. 需要补满时勾选“全部填允许上限”。该操作只填入目标，不立即写入；取消勾选不会自动撤回已经填入的数量。
7. 点击界面中唯一的 **保存** 按钮。成功后弹出“已保存”。
8. 自行启动游戏并继续原存档。

游戏运行时可查看或设置目标，但禁止保存。若读取后存档被游戏或云同步更新，工具会拒绝覆盖，请关闭并重新打开程序。关闭程序会丢弃尚未保存的修改。

## “存档”与时间的含义

“存档”指同一个 `S0000.sl2` 文件内的有效游戏进度槽，不是 Steam 账号，也不是游戏中的另一个可操作人物。

选项示例：

```text
存档 1 | 2026-10-02 21:11:59.344
```

日期时间来自该槽在游戏存档菜单中的**记录时间字段**，精确到毫秒；不是整个文件的修改时间，也不是程序推测的创建时间。当前已验证的数据只支持读取这个记录时间，不能据此承诺它是第一次建立存档的时间。工具原样显示该字段的日期，不猜测时区或做跨时区转换。

- 只显示有效槽；已经删除的残留数据不会作为有效存档列出。
- 各槽独立读取时间。
- 时间缺失或不符合支持格式时显示“时间未知”，不会用文件时间冒充。
- 修改数量不会改写存档菜单记录时间。

## 数量与保护边界

| 项目 | 规则 |
| --- | --- |
| 钱币 Sen | 0～999,999,999 |
| 纸人随身 | 当前存档已解锁容量，不提升容量 |
| 纸人仓库 | 最大 999 |
| 五种糖 | 已有物品通常随身 3、仓库 9999 |
| 药品与其他消耗品 | 按每个物品的本机游戏参数分别限制 |
| 伤药葫芦 | 按当前升级容量补充次数，不升级 |
| 未获得的物品 | 显示为灰色，数量输入禁用，不生成 |

不是所有物品都能填 999 或 9999；随身和仓库上限不同。“全部填允许上限”只处理白名单中已拥有的物品，不等于解锁全部道具。

## 保存机制与风险

- 校验 BND4 容器、12 个条目 MD5、账号标识、有效槽、库存计数与上限。
- 只修改钱币和允许的物品数量及必要的库存字段，不编辑其他存档槽或剧情区域。
- 使用同目录临时文件、回读校验和原子替换；临时文件在正常完成或可处理错误后清理。
- **不保存备份、设置、预设、日志或历史版本。**
- 不删除游戏本身的 `S0000.sl2`，不主动修改游戏产生的 `.bak` 文件或 Steam 云设置。
- 云同步与外部程序的竞争风险无法完全消除。遇到存档变化提示时，不要反复强行覆盖。
- 强制结束进程、断电或磁盘故障仍有风险；程序无法承诺绝对不会丢失数据。

## 常见问题

**没有找到存档？** 先在游戏中创建进度并正常退出。工具扫描的是当前 Windows 用户的 `%APPDATA%\Sekiro`，不是游戏安装目录。

**物品是灰色的？** 当前有效槽没有该道具记录。请先在游戏中正常获得它，再退出游戏重新打开工具。

**数量输完没有变化？** 输入只更新目标，点击“保存”才会写入。

**提示游戏正在运行？** 等待 `sekiro.exe` 完全退出。不要在游戏自动保存期间修改文件。

**提示数据已变化？** 游戏或云同步改变了存档。关闭并重新打开工具后重新设置数量。

**能恢复之前的数量吗？** 本工具没有恢复或撤销功能。可在再次打开时手动填写新数量；这不等于恢复整个旧存档。

**需要联网吗？** 下载可运行包需要网络；工具正常读取、修改和保存本地存档不联网，不上传账号或游戏数据。

## 开发者说明

普通玩家使用 Release 的 EXE 即可，以下内容只面向源码开发者。

- Python 3.12+，带 Tkinter；打包须在 Windows x64 完成。
- 运行源码：`python -B app/gui.py`。
- 单元测试：`python -B -m unittest discover -s tests -v`；使用完全合成的存档，不读取玩家正式存档。
- 构建：`powershell -File build.ps1 -Python python`；会安装 `requirements-build.txt` 中固定版本的构建依赖。
- 输出：`dist/Sekiro Resource Modifier.exe`。构建结束会自动运行隔离环境的 EXE 自测。
- 生成带说明、SHA-256 和第三方许可的 ZIP：`powershell -File package.ps1 -Version v1.0.0`；已有构建可加 `-SkipBuild`。
- 普通用户升级时，先退出工具，把新 ZIP 解压到新文件夹并运行新 EXE；确认正常后可删除旧工具文件夹。本工具没有需迁移的配置或历史数据。不要删除游戏存档目录。
- 可选便携包自测：`"Sekiro Resource Modifier.exe" --self-test-report "report.json"`。仅使用临时合成数据，报告只在明确使用这个开发参数时生成。

| 文件 | 内容 |
| --- | --- |
| `app/gui.py` | 极简图形界面 |
| `app/backend.py` | 校验、时间读取、数量修改与保存 |
| `app/smoke_test.py` | 可运行包显式自测 |

| `third_party_licenses/` | 打包运行时的第三方许可证 |
| `Sekiro Resource Modifier.cmd` | 源码目录备用入口，优先运行构建好的 EXE |

仓库不包含个人游戏存档、真实账号、登录凭证、游戏程序或游戏完整参数文件。发布的是工具源码、必要的白名单参数及打包运行时，不分发游戏本体。
